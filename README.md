# The World in One Day

A deterministic 1024 × 1024 warm-paper broadsheet front page for Thursday 19 November 2026. The artwork is rendered from flat vector geometry and measured type by `gen.py`; `main.ts` copies the finished image into the make.fun output directory.

Run `python3 gen.py` to rebuild `entry.png`.
